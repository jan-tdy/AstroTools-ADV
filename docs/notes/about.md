## What it does

Shows the versions and licenses of the program's dependencies, system information, and the citation text for astropy.

## How to use

Press **Refresh** to read the versions again. **Copy BibTeX** copies the astropy citation.

## Reading the results

**Versions** lists `component, version, license` for Python, the platform, Qt, astropy, astroquery, pyvo, pyerfa, numpy, scipy, matplotlib and PyQt5. **System info** adds details about the machine. **Citation / BibTeX** has the text to cite astropy.

## Tips and limits

- Quote the versions in a bug report or a paper's software list.
- See [Licensing](../../project/licensing.md) for the terms of the program and its dependencies.
